## 개요
이 워크플로우는 대표님의 요청에 따라 프로젝트를 Netlify(`aiaimag.netlify.app`)에 업데이트하는 절차를 정의합니다.

## 절차
1. **코드 변경 확인**: 수정된 사항이 `index.html`, `ai-style.css`, `ai-app.js` 등에 모두 반영되었는지 확인합니다.
2. **빌드 및 검증**: (필요 시) 로컬에서 변경 사항이 정상적으로 작동하는지 최종 확인합니다.
3. **업데이트 브리핑**: "대표님, 요청하신 내용을 반영하여 Netlify에 올릴 준비가 되었습니다!"라고 브리핑합니다.
4. **배포 방식**: 현재 직접적인 CLI 배포가 설정되어 있지 않으므로, 파일 수정 후 대표님께 직접 업로드나 Git Push를 안내해 드립니다. (추후 자동화 필요 시 대표님께 건의)

## 참고 사항
- Netlify URL: [aiaimag.netlify.app](https://aiaimag.netlify.app)
- 담당 부장: 코다리 부장
